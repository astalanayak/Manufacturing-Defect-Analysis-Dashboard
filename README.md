# Manufacturing-Defect-Analysis-Dashboard
An interactive Power BI dashboard for analyzing manufacturing defects, repair costs, defect severity, defect types, inspection methods, and defect locations. The dashboard provides KPI metrics, visual insights, and filtering capabilities to support quality control and decision-making in manufacturing processes.
Manufacturing Defect Analysis Dashboard
Overview
This project presents an interactive Power BI dashboard designed to analyze manufacturing defects and quality performance. The dashboard helps identify defect patterns, monitor repair costs, evaluate inspection methods, and track defect severity across different manufacturing locations.

Key Features
Total Defects KPI
Total Repair Cost KPI
Defects by Type Analysis
Defects by Severity Analysis
Defects by Location Analysis
Inspection Method Analysis
Interactive Filters (Slicers)
Tools Used
Power BI Desktop
CSV Dataset
GitHub
Business Benefits
Improves quality monitoring
Identifies critical defect areas
Helps reduce manufacturing losses
Supports data-driven decision making
